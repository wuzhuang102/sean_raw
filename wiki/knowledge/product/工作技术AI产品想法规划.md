# 2026-06

## 2026-06-04 | Cat Wu 关于PM 的思考

产品品味，学会做减法代码编写成本逐步趋近于零，产品经理的核心能力不再是落地执行，而是懂得取舍、决定不做什么。实操上优先用自然语言交互解决问题，不做复杂定制 UI，前端只聚焦高密度信息排版。金句：The cost of writing code is going to zero, so deciding what to build becomes much more valuable than the execution itself.

2. 提速研发：用原型替代文档（Demos not memos）摒弃厚重 PRD，依靠原型快速验证。借助工具快速产出原型、收集真实反馈，数小时内就能判定功能取舍，把传统半年的研发周期，压缩至一个月甚至一天。金句：We've shortened development cycles from six months to one day. From docs to demos.

3. 理清模型与产品的边界项目初期不必刻意降本用低配模型，也别过早做冗余优化。切忌为弥补当下大模型的能力短板，开展长周期开发。产品设计要和模型迭代解耦，先用旗舰模型跑通流程，静待技术自然升级、成本下降。

4. 重新定义 AI：做思维伙伴打造具备自省能力的 AI，让模型主动复盘问题、认清自身边界，从单纯的指令执行者，转变为协作搭档。金句：Asking the model to introspect on its own mistakes is a key skill.
