# 定位

这页用于沉淀可长期复用的技术学习资料入口，优先收纳具备专题结构、分类体系或系统化课程目录的站点，而不是零散单篇文章。目标不是替代具体知识页，而是给后续补课、面试准备和专题深挖提供稳定导航。

# 收录规则

- 优先收录有明确分类体系的技术站点、课程目录、专题专栏和系统化学习入口。
- 每个条目只保留一句话定位和来源链接，不展开到逐篇文章级别。
- 当某个资料源反复被引用，或其中某一专题已经形成长期知识，再拆到对应 `knowledge/` 页面。

## AI 与 Agent 工程

- [Harness 101](https://my.feishu.cn/wiki/L082wubkdie8uMkRUjgceKYQnIe): Agent Harness 系列学习入口，覆盖 ReAct Loop、模型之外的系统能力、工具、Company Brain、Context Offloading、虚拟文件系统和 Long-horizon Agent 等主题。
- Agent 学习项目：
  - [hello-agents](https://github.com/datawhalechina/hello-agents): Datawhale《从零开始构建智能体》教程，面向 Agent 原理与实践入门，覆盖 LLM、RAG 和智能体构建相关内容。
  - [mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent): SWE-agent 团队的极简软件工程 Agent，适合学习线性消息历史、命令行环境和 GitHub issue 修复型 Agent 的最小实现。
  - [nanobot](https://github.com/HKUDS/nanobot): 轻量个人 AI Agent 框架，适合观察小核心如何组合 WebUI、聊天渠道、工具、记忆、MCP、模型路由和部署能力。
  - [hermes-agent](https://github.com/nousresearch/hermes-agent): Nous Research 的自改进 Agent 项目，适合学习长期记忆、skill 生成、跨会话检索、多渠道入口和可部署 Agent 运行时设计。
