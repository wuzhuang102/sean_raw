## VoltAgent

- Repository: https://github.com/VoltAgent/voltagent
- Website: https://voltagent.dev/
- Documentation: https://voltagent.dev/docs/
- README source checked: https://raw.githubusercontent.com/VoltAgent/voltagent/main/README.md

Relevant source notes from README:

- VoltAgent describes itself as an "AI Agent Engineering Platform".
- It has two major parts:
  - An open-source TypeScript framework for memory, RAG, guardrails, tools, MCP, voice, workflow, evals, and agent runtime concerns.
  - VoltOps Console for observability, automation, deployment, evals, guardrails, prompts, and operations.
- The framework includes core runtime, workflow engine, supervisors/sub-agents, tool registry, MCP integration, model-provider compatibility, memory, resumable streaming, retrieval/RAG, voice, guardrails, and evals.
- The examples list includes Slack, Airtable, WhatsApp order agents, YouTube-to-blog, ad generation, recipes, and research assistant workflows.

## awesome-design-md

- Repository: https://github.com/voltagent/awesome-design-md
- README source checked: https://raw.githubusercontent.com/voltagent/awesome-design-md/main/README.md
- Referenced DESIGN.md concept: https://stitch.withgoogle.com/docs/design-md/overview/
- Request site: https://getdesign.md/request

Relevant source notes from README:

- awesome-design-md is a curated collection of DESIGN.md files inspired by developer-focused websites.
- DESIGN.md is described as a plain-text design system document that AI agents can read to generate consistent UI.
- The collection is organized by product/category, including AI and LLM platforms, developer tools and IDEs, backend/database/DevOps, productivity/SaaS, design and creative tools, fintech and crypto, e-commerce and retail, media and consumer tech, and automotive.
- Each DESIGN.md captures visual theme, color palette, typography, component styling, layout principles, depth/elevation, do's and don'ts, responsive behavior, and an agent prompt guide.
- Each site entry is intended to provide a DESIGN.md and visual previews.
