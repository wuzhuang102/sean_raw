### 2026-06-09 | Harness 101：Loop Engineering—从 ReAct 到 Orchestration
- link: https://my.feishu.cn/wiki/ToaRw8BAUiAyFFkR3EAc05atnsg
- summary: 文章把 Loop Engineering 定义为从“手写 prompt”转向“设计会反复 prompt agent 的 loop”：把找活、拆解、派发、验收、记录和下一步决策固化成可重复运行的系统。它区分了 Skill 与 Dynamic Workflow：Skill 把结构交给模型临场执行，Workflow 则把阶段顺序、并行、循环、分支和断点续跑写进代码，只在 `agent()` 与 `assert()` 等调用点把判断力交给模型。适合阶段清晰、可验收、需反复执行和审计的任务；边界模糊的一次性探索仍更适合对话或 Skill。
- tags: `agent`, `loop-engineering`, `workflow`, `orchestration`, `react`, `skill`, `harness`, `ai-engineering`
